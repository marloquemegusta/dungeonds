# abanderado_solo

El Abanderado solo con su estandarte (sin cortejo de exvotos), 320x320 por celda, para los vídeos de lore. Se regenera con `tools/characters/build_abanderado.py` y `node tools/lab/export_character_headless.cjs assets/models/characters/abanderado/abanderado_walk.fbx <salida> --template tools/characters/abanderado_lab_template.json --anim abanderado_walk --resolution 320 --fitZoom 0.88 --legibility c2`.
