# assets/sprites/characters/

Paquetes de sprites de personaje que lee `tools/generate_player_sprites_c.py`. Una carpeta por entrada de `characters.json`. Se regeneran con `python tools/rebuild_all.py --only characters,bake --char <entrada>`; no se exportan a mano desde el lab.

Qué modelo y qué animación producen cada carpeta, la regla de escala fija y los pasos para regenerar: [`assets/MANIFEST.md`](../../MANIFEST.md) §2.
