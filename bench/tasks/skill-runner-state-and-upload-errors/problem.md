# Aplicar todas las cotas de aserción y tolerar stderr de curl

Las aserciones de rango pueden pasar aunque el valor exceda el límite superior porque solo se evalúa una condición. Por separado, Windows PowerShell 5.1 puede abortar una subida FTP exitosa al tratar el stderr nativo de curl como error. Haz que todas las condiciones presentes sean obligatorias y que el resultado FTP dependa del código de salida y la verificación remota.
