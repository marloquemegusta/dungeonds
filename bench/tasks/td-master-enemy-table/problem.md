# Unificar estadísticas de enemigos en una tabla maestra

Spawn, recompensas, mordida, sandbox y pantalla de estadísticas mantienen valores duplicados. Consolida las estadísticas por especie y tier en una única fuente de verdad que consuman esos sistemas. El proyecto corre en C/ARM9 sin FPU; entrega build y escenario que comprueben tiers.
