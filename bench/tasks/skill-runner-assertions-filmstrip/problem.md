# Añadir aserciones de estado y capturas secuenciales al runner

El runner de escenarios debe validar comportamiento del juego más allá de capturas aisladas. Añade aserciones de estado y secuencias de capturas, y corrige entradas de keypad si el estado retenido o la navegación entre pasos no coinciden con el escenario. Mantén el runner genérico para proyectos Nintendo DS.
