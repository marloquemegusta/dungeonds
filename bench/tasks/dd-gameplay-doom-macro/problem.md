# Completar el ciclo de combate y progresión Doom-style

El juego tiene movimiento y una mazmorra, pero carece de un ciclo completo de combate y progresión. Añade salud y armadura, enemigos con comportamientos distintos, armas seleccionables, apuntado táctil y encuentros por salas con recompensas y salida. La Nintendo DS no tiene FPU: la lógica de juego debe usar enteros o punto fijo, respetar 4 MB de RAM y mantener el presupuesto de 560190 ticks por frame. Entrega build limpia, pruebas host y escenarios que cubran el combate y la progresión.
