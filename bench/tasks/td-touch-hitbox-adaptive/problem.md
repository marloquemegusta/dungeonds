# Hacer que el stylus seleccione la silueta visible

Los enemigos tienen sprites con distintos tamaños, offsets, frames y altura de vuelo; el punto lógico no coincide siempre con la silueta visible. Ajusta la selección táctil para que tocar el cuerpo dibujado seleccione al enemigo sin perder una zona de gracia consistente. Mantén el comportamiento de disparo y la plataforma DS.
