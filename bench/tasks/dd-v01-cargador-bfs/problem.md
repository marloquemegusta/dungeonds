# Hacer que el cargador rodee obstáculos

El cargador debe alcanzar al jugador aunque un muro corte la línea directa. Implementa navegación compatible con la colisión real, sin diagonal que corte esquinas. La búsqueda debe poder repartirse entre frames; no uses float ni double. Entrega tests host y un escenario cuya ruta atraviese de verdad una esquina de muro.
