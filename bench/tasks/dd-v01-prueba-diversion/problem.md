# Construir la prueba de diversión v0.1

Implementa una prueba jugable corta de combate para Nintendo DS: dos armas distintas, dos arquetipos de enemigo y cuatro arenas encadenadas. Mantén el código de juego sin float ni double, trabaja con punto fijo y límites de memoria/OAM de DS. Entrega runtime integrado, pruebas de host y escenarios que demuestren combate, navegación, cambio de arena y oclusión.
